# 掌中灵电脑端守护工具（zzl）

掌中灵电脑端打开无障碍快捷方式，可以卸载软件，打开无障碍，注册设备管理。

## 这是什么

一个在**电脑（Windows）**上运行的小工具，通过 adb 帮你在孩子的平板上把掌中灵的被控端配置到位。
孩子平板上的「无障碍」和「设备管理器」这两道权限，**一旦被关掉，掌中灵的管控就会被绕过**；
这个工具用来检查它们的状态，并在被关掉时帮你一键重新打开。

适用设备：联想平板 TB372FC（ZUI 16），包名 `com.zzl.guardian.child`。

## 能做什么

| 能力 | 说明 |
|---|---|
| 打开无障碍快捷方式 | 检查掌中灵无障碍服务是否开启，已关则引导重新打开（系统设置路径一键直达） |
| 注册设备管理 | 检查掌中灵设备管理器（防卸载）是否激活，未激活可一键激活 |
| 授予 WRITE_SECURE_SETTINGS | DNS 防护需要该权限，一条命令完成授权 |
| 一键卸载掌中灵 | 退出管控 / 卸载被控端（需要先在系统里撤销设备管理器） |
| 状态体检 | 一次性列出无障碍、设备管理器、权限、保活等关键状态 |

## 怎么用

1. 用**数据线**连接平板（纯充电线不行），平板下拉通知栏把 USB 连接方式选「传输文件 / MTP」
2. 平板上已开启「USB 调试」，并解锁屏幕（首次连接会弹「允许 USB 调试吗」，勾选「一律允许」）
3. 双击运行 **`掌中灵检查.bat`**
4. 按提示选择操作：检查状态 / 打开无障碍 / 注册设备管理 / 授权 / 卸载

也可以直接命令行调用：

```powershell
powershell -File zzl_guard.ps1            # 打开菜单
powershell -File zzl_guard.ps1 check      # 只体检
powershell -File zzl_guard.ps1 grant      # 授予 WRITE_SECURE_SETTINGS
powershell -File zzl_guard.ps1 uninstall  # 一键卸载掌中灵
```

## 目录结构

```
zzl/
├── 掌中灵检查.bat        ← 双击这个（菜单入口）
├── zzl_guard.ps1         ← 全部逻辑（adb 调用与 UI 自动化）
└── adb_tools/platform-tools/   ← 自带的 adb，免去单独装环境
```

## 常见问题

- **检测不到平板**：换数据线/换 USB 口；平板解锁；确认 USB 调试已开；关闭手机管家等第三方安全软件的 USB 管理限制
- **状态是 unauthorized**：在平板弹窗里勾选「一律允许」并确定
- **UI 自动化点不中**：把平板停留在设置页、保持屏幕常亮（脚本会自动 `svc power stayon`），避免中途熄屏
- **中文乱码**：脚本已强制 UTF-8 输出，若仍异常请用 Windows Terminal 运行

## 安全说明

- 工具只通过 adb 操作**你自己已连接的这台设备**，不联网、不上传任何数据
- 仓库中已移除开发机的本机绝对路径，可安全分发
- 卸载掌中灵属于高风险操作（会同时解除防卸载保护），请确认后再执行
