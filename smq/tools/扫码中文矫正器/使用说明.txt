扫码中文矫正器  v1.1  —— 免安装版使用说明
==================================================

【能不能在没权限、没装 Python 的电脑上用？】
能。这个 exe 是打包好的单文件程序：
  · 不需要安装，不需要管理员权限（不写注册表、不装驱动、不联网）
  · 不需要装 Python 或任何运行库
  · 整个文件夹拷到 U 盘，插到目标电脑上双击 exe 就能用

【第一次运行时可能被拦一下】
  1) 如果弹出 "Windows 已保护你的电脑"：
     点【更多信息】→【仍要运行】。这是因为文件没有数字签名，不是病毒。
  2) 如果杀毒软件报毒：把该文件夹加入信任即可（PyInstaller 打包的程序偶尔被误报）。
  3) 如果系统提示 "无法启动此程序"：说明目标电脑缺 .NET/Tk 运行环境，
     那就改用同名文件夹里的【源码】版本（需要装 Python）。

【两种用法，按你的情况选】

━━ 路线 A：扫描枪走蓝牙 SPP（推荐，一劳永逸）━━
  1. 先扫【设置码速查.png】里的 ① 蓝牙 SPP 模式。
  2. Windows 设置 → 蓝牙和其他设备 → 添加设备 → 配对扫描枪。
  3. 设备管理器 → 端口(COM 和 LPT) 里会多出 "蓝牙链接上的标准串行 (COM x)"。
  4. 打开本程序的【串口模式】：
       串口 = 那个 COM x      编码 = gbk     点"打开串口"
       勾上"收到后直接键入到当前光标处"，把本窗口最小化。
  5. 之后鼠标点进网页输入框/记事本，直接扫码 → 里面出现的就是正确中文。
     （SPP 是字节流，程序按 GBK 解码后用 Unicode 键入，一个字节都不会丢。）

━━ 路线 B：不改扫描枪设置，让本程序当中转 ━━
  1. 打开【键盘模式】。
  2. "目标窗口"下拉框里选你的网页/业务软件，勾"扫完自动回填"。
  3. 光标留在本程序的输入框里，扫一下 → 自动还原成中文并送回目标窗口。
  4. 如果没有目标窗口需求：扫完点"复制到剪贴板"再 Ctrl+V 也行。

【为什么会乱码】
  标签二维码里存的是 GBK 编码的中文（例如 沪 = BB A6 两个字节），
  扫描枪在"键盘模式"下只能模拟按键、一次打一个字符，没法把两个字节合成一个汉字，
  于是电脑上就显示成 »¦ 这样的西欧字母。这就是乱码的由来，二维码本身没问题，
  也不用重新印标签。
  YC200D 这台机器固件里没有"GBK/UNICODE 输出"选项（同厂 EP-8600 才有），
  所以必须在接收端做转换 —— 也就是本程序干的事。

【目录里都有什么】
  扫码中文矫正器.exe   ← 主程序，双击运行
  设置码速查.png/.pdf  ← YC200D 常用设置码，屏幕 100% 缩放直接扫
  YC200D说明书.pdf     ← 官方 40 页说明书（设置码原页：13/16/18/19 页）
  测试码_同7678.png    ← 与 7678.pdf 内容完全一致的测试码，用来反复验证设置
  源码\                ← Python 源码，需要改功能时用

【小提示】
  · 扫码时把电脑输入法切到英文，中文输入法会吞掉高速按键。
  · 设置码扫完"嘀嘀"两声＝成功；设乱了扫 ③ 初始化主控设置 复位。
  · 如果记事本正常、只有某个网页系统乱 → 是那个系统自己在解码，
    用路线 B 回填绕过，或让开发把接收端按 GBK 解。
