免 root 的安卓儿童平板监管系统 ｜ 适用于 1.0.0

1. 先花 3 分钟了解全貌

这套系统由三个部分组成，缺一不可：

控制端（家长手机）

  • 设定每天能用多久、哪些应用能用、几点到几点能用
  • 查看使用报告、拦截记录、截屏
  • 临时加时、放行某个应用、立即锁机
  • 审批孩子发来的「申请加时」

被控端（儿童平板）

  • 按家长设定的规则自动拦截，规则存在本地，断网也照常管
  • 无法自行卸载，无法简单退出
  • 到时弹全屏遮盖页，并把孩子挡回桌面
  • 孩子可在拦截页上「申请加时」
服务器不保存屏幕内容 截屏只有在家长主动点一次的时候才拍一张，拍完即传即存，服务器上保留 60 张 / 30 天（可在 .env 里调）。它不会定时截、更不会实时录屏。
开始之前，请先想清楚两件事

1. 这套软件是为「和 7～14 岁孩子达成的约定」设计的，不是用来偷偷监视的。 被控端的常驻通知会一直显示剩余可用时长，孩子看得见。请提前和孩子说清楚规则。

2. 请务必先自己走通一遍再交给孩子。 特别是第 3 章的权限，漏一项就会「看着装了但管不住」。

2. 部署服务器（一次性，约 15 分钟）

服务器的作用是让家长手机和孩子平板能互相找到对方。它必须放在公网上， 否则孩子在外面用流量时，家长就下发不了指令。

本项目默认使用阿里云轻量应用服务器。最便宜的 2 核 2G 配置完全够用 （同时管十几台设备也没压力）。

2.1 装 Docker

SSH 登录服务器后执行：

curl -fsSL https://get.docker.com | sh -s -- --mirror Aliyun
systemctl enable --now docker

2.2 配置镜像加速 必做

不配这一步，拉取 Node 镜像会慢到超时。加速地址在 阿里云控制台 → 容器镜像服务 → 镜像加速器 可以拿到专属地址：

sudo mkdir -p /etc/docker
sudo tee /etc/docker/daemon.json <<'JSON'
{
  "registry-mirrors": ["https://你的专属地址.mirror.aliyuncs.com"]
}
JSON
sudo systemctl daemon-reload
sudo systemctl restart docker

2.3 放行安全组端口 最容易漏

不做这一步，服务是好的，但 App 永远连不上 阿里云控制台 → 找到你的服务器 → 安全组 / 防火墙 → 入方向 → 添加规则 → 协议 TCP，端口 8111，授权对象 0.0.0.0/0。

2.4 上传并一键部署

在你本机的项目目录里（已生成部署包 zzl-deploy.tar.gz）：

# 换成你的服务器公网 IP
scp zzl-deploy.tar.gz root@203.0.113.10:/opt/

ssh root@203.0.113.10 "mkdir -p /opt/zzl && cd /opt/zzl && tar -xzf /opt/zzl-deploy.tar.gz"

ssh root@203.0.113.10 "cd /opt/zzl/deploy && chmod +x install.sh && ./install.sh"

脚本会自动生成随机密钥、构建镜像、启动容器，并做一次健康检查。 看到 部署完成 就成功了。

2.5 验证

# 在服务器上
curl http://127.0.0.1:8111/api/health
# 期望输出：{"ok":true,"service":"zhangzhongling","serverTime":...}

# 也可以在你自己电脑的浏览器里试
#   http://203.0.113.10:8111/api/health   （203.0.113.10 为示例地址，换成你自己的）
# 能打开说明安全组也放行好了
换端口 改 /opt/zzl/deploy/.env 里的 APP_PORT，然后 cd /opt/zzl/deploy && ./install.sh --update。 记得安全组同步放行新端口。

2.6 备份（建议设成定时任务）

docker compose exec zzl-server sh -c 'tar -czf - /data' > zzl-backup-$(date +%F).tar.gz

备份文件里包含数据库与截屏图片。换服务器时把它恢复回 /data 卷即可， 不用重新配对设备。

3. 家长手机装控制端

3.1 安装

把 app-parent-release.apk 传到手机（微信文件传输助手、数据线、网盘都行）， 点击安装。若提示「不允许安装未知应用」，按系统引导允许即可。

Play Protect 会提示「应用存在风险」 管控类应用会申请读取应用列表等敏感权限，被 Google 标记属于正常现象。 选「仍然安装」即可。

3.2 填写服务器地址

  1. 打开「掌中灵·控制端」，在登录页点 服务器设置
  2. 主机填 203.0.113.10（示例地址，换成你自己的公网 IP 或域名），端口填 8111 （新装的 App 已默认 8111，一般不用改；如手动改过请以 .env 里的 APP_PORT 为准）
  3. 点「测试并保存」——它会真的去请求一次 /api/health， 连不上会明确告诉你原因（地址解析失败 / 连接超时 / 拒绝连接）

3.3 注册账号并生成配对码

  1. 注册一个账号（邮箱 + 密码），登录
  2. 点「添加设备」→ 生成一个 6 位配对码
配对码 5 分钟内有效 生成后请立刻在平板上输入。过期了重新生成一个就行，没有次数限制。

4. 儿童平板装被控端 ★

这一章是整本手册最重要的部分。被控端必须拿到 3 项权限、完成 1 次配对 才能真正管住设备；漏掉任何一项，都会出现「装了但不起作用」。

4.1 安装 APK

把 app-child-release.apk 传到平板并安装。 安装位置建议选本机存储而不是 SD 卡。

4.2 允许「受限设置」Android 13+ 必做

这是装机时最容易卡住的一步

从浏览器、微信等渠道侧载安装的应用，Android 13 及以上默认 禁止开启无障碍服务——开关会一直是灰的，点不动。

必须先手动解除这个限制：

打开后回到无障碍设置页，原来的灰色开关就变得可以点击了。

找不到这一项？ 部分厂商 ROM（如 MIUI、HarmonyOS）把它藏在「设置 → 应用 → 掌中灵 → 权限」里， 或干脆没有这个限制。被控端 App 的权限页上有「打开本应用详情页」按钮，可以直接跳过去。

4.3 配对

  1. 打开被控端 App，在配对页填写服务器地址（和家长手机一致）
  2. 输入家长手机上显示的 6 位配对码，点「绑定」
  3. 看到「已绑定」即可。此时家长手机的设备列表里会出现这台平板

4.4 逐项授予权限 决定管控是否真的生效

配对完成后，App 会列出待开启的权限。三项缺一不可：

权限作用不开的后果
无障碍服务
必需		 感知当前打开的是哪个应用。这是管控的「眼睛」，没有它系统不知道孩子在用什么 完全不起作用。不计时、不拦截、连使用报告都是空的
使用情况访问
必需		 读取各应用的使用时长记录，用于统计与补算 使用报告的数字不准；进程被杀后重启无法补齐时长
悬浮窗
必需		 用于弹出全屏拦截页 时长到了也不会拦截——孩子可以一直玩下去
通知
Android 13+ 建议开		 显示常驻的剩余时长通知 常驻通知看不见，家长也少了一条「服务活着」的证据
设备管理器
加固项		 阻止孩子直接卸载本应用 管控照常生效，但孩子可以在设置里「取消激活」后卸载。家长会收到通知
为什么设备管理器不算「必需」 它不影响管控是否生效，只影响「能不能被绕过」。放在必需品清单里会让家长看到 「还有 1 项未开启，管控无法生效」，但实际上管控已经在工作了——那反而更让人困惑。

4.5 电池优化与自启动 否则会被系统悄悄杀掉

安卓系统会为了省电清掉后台应用。被控端一旦被杀，管控就停了。必须把它加入白名单。

  1. 电池优化豁免 权限页上有「电池优化设置」按钮，把掌中灵设为不优化 / 无限制。
  2. 允许自启动 厂商 ROM 特有。设置 → 应用管理 → 掌中灵 → 允许自启动 / 允许后台运行。

App 的「保活健康度」页会按四个维度显示当前状态： 前台服务 / 电池优化豁免 / 精确闹钟 / 厂商白名单。 四项都绿是最理想的；至少前两项必须是绿的。

4.6 激活设备管理器

在权限页点「激活设备管理器」，系统会弹出确认框，点「激活」。

激活后，孩子尝试卸载时会被挡住。若孩子主动去「取消激活」，被控端会：

  • 立刻把管控服务重新拉起来
  • 给家长推送一条通知
  • 在本地留下一笔记录（可在控制端的审计日志里看到）

它做不到阻止取消激活，但能做到让取消无法悄悄进行。

4.7 （可选，最强）激活为 Device Owner

设备管理器模式已经够用。如果你想要「孩子连设置里的取消激活都点不到」， 可以进一步把被控端激活为 Device Owner（设备所有者）。 这是安卓提供的最高权限级别，代价是需要一次 ADB 操作。

前提条件很严格 设备必须没有登录过任何账号、没有设置过锁屏密码。 如果平板已经用了一段时间，通常只能先恢复出厂设置。

请务必先想清楚再动手。 Device Owner 无法在系统设置里取消激活。
Device Owner 与设备管理器，能力差多少？
能力设备管理器Device Owner
阻止普通卸载可（孩子可先取消激活绕过）强制，且无法取消激活
隐藏桌面图标仅隐藏桌面图标系统级，设置里也看不到
禁止恢复出厂设置不可可，但本项目默认关闭（给家长留后路）

5. 配置管控规则

回到家长手机。点设备卡片进入配置。四个入口：

5.1 时长规则

项目说明
上学日 / 周末时长分别设置。比如上学日 60 分钟、周末 120 分钟
额度重置时间默认 0 点归零。建议设为凌晨 4 点——孩子熬夜的话，0 点归零等于给了他一个全新的额度
启用管控总开关。关掉后所有规则失效
允许申请加时打开后，孩子被拦时能看到「申请加时」按钮

5.2 应用管控

  • 黑名单模式：名单里的应用不能打开。适合只禁游戏和短视频。
  • 白名单模式：只有名单里的应用能打开。适合低龄孩子，管控更彻底。
  • 逐应用规则：可以给单个应用单独设每日上限和允许时段， 比如「微信每天 30 分钟，19:00–20:00 之间」。
  • 用时不计入当日总时长：展开某个应用后打开这个开关，它消耗的时间就不占 当天的总时长，总时长用完后它仍然打得开。典型用法是让学习类应用 不被娱乐额度拖累。注意该应用自己的「单日上限」和「允许时段」照常生效， 所以它不会变成无限使用 —— 想限制时，给它单独设一个每日上限即可。

点「刷新应用清单」可以让平板重新上报一次已安装应用。系统组件不会出现在清单里。

放行一个应用 ≠ 给了无限额度 即使你单独放行了「作业帮」，它仍然消耗当天的总时长。 这是刻意的：放行是「允许用」，不是「不限量」。

5.3 限制工具（临时操作）

操作效果
立即锁定平板上立刻弹出全屏锁定页，压过一切规则，且不给孩子申请入口
加时+15 / +30 / +60 分钟。只对当天有效，过了归零点自动失效
单应用放行指定一个应用在指定时间内可用，仍受总时长约束
临时总解封一段时间内完全不限。适合周末或假期

所有生效中的授权都列在下方，可以随时撤销。

5.4 使用报告与截屏

  • 使用报告：今日额度进度、近 7/14/30 日趋势、应用排行、拦截记录、会话时间线
  • 截屏：点一次拍一张，不是定时也不是实时。Android 11 以下拍不了（见附录）
  • 审计日志：谁在什么时候做了什么，全部留痕
离线也能管 规则和当天的计时都存在平板本地。平板断网时，管控照常生效， 使用记录先攒着，联网后自动补传。断网不是绕过管控的办法。

6. 离线密码

用于在没有网络、或家长手机不在身边时紧急处理。分三级，能力递增：

级别能做什么典型场景
L1 日常加时（+15 / +30 / +60）说好了多看半小时，但手机没带
L2 管理放行某个应用、解除某应用的时段限制临时需要用一下某个被禁的应用
L3 超级退出管控、解除设备管理器、卸载本应用彻底不用了，或要转手设备

6.1 设置密码

在控制端设备卡片上点「设置离线密码」（尚未设置密码时按钮会显示这个名字并标红； 设置过之后叫「设备加固」）打开面板，里面可以逐级设置或清除密码，也可以在被控端本地设置。 密码要求至少 6 位，且不能是 123456、生日、连号这类弱口令。

密码忘掉就麻烦了 系统只保存密码的哈希值（PBKDF2，12 万次迭代），无法找回，只能重置。 建议用家长自己记得住、孩子猜不到的 6 位数字，并写在一个安全的地方。

好在即使忘了 L3，你仍可以：用家长手机远程重置（需设备在线）， 或者对平板做恢复出厂设置——本项目默认不禁用恢复出厂设置，就是为这种情况留的后路。

6.2 在哪里输入密码

密码输入框直接显示在拦截页上——孩子被挡住时，家长在 「申请加时」按钮下方就能看到「家长密码」输入框，输入密码点「验证」即可。 验证通过后会展开对应的操作按钮：

密码级别验证通过后可执行
日常密码（L1）+15 / +30 / +60 / +120 分钟四档加时
管理密码（L2）加时 · 放行当前被拦的应用 30 分钟
超级密码（L3）加时 · 放行应用 · 退出管控（需二次确认）
旧版本的三个隐藏入口（连点标题 5 次 / 长按右下角 3 秒 / 拨号盘 *#*#8899#*#*）已移除：真机上入口难发现、 弹出的密码界面又会被拦截页挡住。现在一切都在拦截页上直接完成。

6.3 输错会怎样

错误 5 次锁 10 分钟，10 次锁 1 小时。失败尝试会记录并上报， 家长可以在「设备加固」面板里看到孩子的破解尝试记录。

8. 故障排查

现象原因与处理
App 连不上服务器 ① 安全组是否放行端口 8111（最常见）② 服务器上 curl http://127.0.0.1:8111/api/health 是否正常 ③ 容器是否在跑：docker compose ps
管控完全不生效 九成是无障碍服务没开，或开了但被系统关掉了。 看控制端设备卡片上的权限状态；被控端「权限」页也会显示
到点了却不拦截 检查悬浮窗权限。无障碍负责判断，悬浮窗负责弹页面，缺一不可
用着用着就不管了 被系统省电策略杀掉了。去设置里把掌中灵设为不优化电池、 允许自启动。厂商 ROM（小米/华为/OPPO/vivo）尤其要注意
使用报告里「今日用量」是 0 服务器时区不对。检查 .env 里是否为 TZ=Asia/Shanghai， 改完 ./install.sh --update 重建容器
无障碍开关是灰的，点不动 Android 13+ 的受限设置没开。见 4.2 节
截屏一直失败 平板是 Android 10 或更低。系统限制，无解——见附录
配对码无效 超过 5 分钟过期了，重新生成一个
孩子能自己卸载 设备管理器没激活，或者已被取消激活。控制端会收到通知，重新激活即可
想换一台服务器 把备份的 /data 恢复到新服务器，改 App 里的服务器地址即可。 不需要重新配对

在服务器上看日志

cd /opt/zzl/deploy
docker compose logs -f zzl-server        # 实时日志（Ctrl+C 退出）
docker compose restart                   # 重启服务
docker compose exec zzl-server node scripts/smoke.js   # 端到端自检

9. 退出管控与卸载

顺序不能乱 卸载前必须先在 App 内「退出管控」。直接卸载会被设备管理器拦住， 而且本地残留的保活组件下次开机还会尝试把服务拉起来。
  1. 在控制端解除所有限制 限制工具 → 撤销全部生效中的授权；如果是锁定状态，先解除锁定。
  2. 在被控端退出管控 用 L3 超级密码呼出密码键盘 → 选择「退出管控」。 这一步会依次：停止服务 → 取消保活任务与闹钟 → 清除配对会话 → 清空本地策略与密码 → 解除卸载阻止 → 引导取消设备管理器。
    顺序是刻意设计的：漏掉「清除配对会话」的话，第二天开机会把管控重新拉起来。
  3. 取消设备管理器激活 按引导进入设置 → 安全 → 设备管理应用 → 掌中灵 → 取消激活。
  4. 卸载两个 App 此时可以正常卸载了。若之前激活过 Device Owner， 还需先在「设备加固」面板里解除，否则卸载会被系统拒绝。
  5. （可选）清理控制端条目 被控端退出后，控制端列表里它还会以「离线」状态显示。 点设备卡片上的「删除」并确认，即可移除这条记录—— 服务器会连同该设备的策略、使用记录与截屏文件一起删除； 若设备此时仍在线，它会收到通知并自动回到配对页。 以后重新配对：记录已删除就新增一条，没删除就沿用原记录（同一台平板不会出现两条）。

10. 附录：能力边界

这一节列的是系统限制，不是软件缺陷。提前知道能省很多困惑。

10.1 截屏

平板系统版本能否远程静默截屏说明
Android 11 及以上能用无障碍服务截图，孩子完全无感知
Android 10 及以下不能系统没有提供无声截图接口
为什么低版本不做「弹窗授权」的降级方案 另一条技术路线是使用系统录屏授权，但它必须当着孩子的面弹出一个确认框。 孩子点「取消」之后照样拿不到图——既暴露了「正在被监控」这个事实，又失败了。 相比之下，明确告诉你「此设备不支持」是更诚实的选择。

10.2 隐藏图标

模式效果
Device Owner系统级隐藏：在「设置 → 应用」里也看不到
设备管理器 / 普通仅隐藏桌面图标：应用列表里仍能找到并打开

隐藏只是「降低存在感」。真正的防绕过靠的是设备管理与无障碍，不是把图标藏起来。

10.3 其他已知限制

  • 「免 root」的代价：没有 root 就无法做到「绝对无法绕过」。 这套方案的目标是让绕过变得足够麻烦、并且一定留下痕迹，而不是提供技术上的绝对封锁。
  • 无法拦截系统设置本身：孩子仍能进入系统设置页面。 设备管理器被取消激活时你会收到通知，这是设计上的兜底。
  • 厂商 ROM 差异：小米、华为、荣耀、OPPO、vivo 的后台管理策略各不相同， 保活效果有别。App 内的「保活健康度」会显示四维状态供你逐项检查。
