# 掌中灵 · 本地模式设计文档（局域网直连，无服务器）

> 状态：一期实现中 ｜ 子端（监听/发现/配对/策略/锁定）已落地 v1.0.13；家长端通道与界面下一步
> 配对载体一期为手动配对码（设备码+令牌+IP，经被控端通知展示），二维码为三期
> 原则：**服务器模式一行不改、行为零变化**；本地模式是并行的一条通路，由家长端显式选择。

---

## 1. 目标与非目标

### 目标
1. 没有服务器的家庭，下载安装后**开箱即用**：扫码配对 → 同一局域网内完成规则设置、锁定/加时、查看报告与截屏。
2. 配对**不依赖任何服务器**：密钥在设备本地生成，二维码面对面分发。
3. 网络切换（换 WiFi / 换 AP / 路由器重启 / IP 变化）后**自动重连**，无需重新扫码。
4. 家庭数据可选择**完全不出户**。
5. 服务器模式**保持原样**：账号登录、跨网远程、服务器侧存储与报告全部不变。

### 非目标（明确不做）
- 跨网络远程管控（物理不可达，属服务器模式职责）
- 多家长端同时在线协同编辑（本地模式同一时刻只允许 1 个家长端连接）
- 替换服务器端的历史数据仓库（云端历史仍属服务器模式）

## 2. 总体架构

```
┌─────────────┐   ① 扫码（面对面，物理通道）   ┌─────────────┐
│  家长端      │ ───────────────────────────▶ │  被控端      │
│ local mode   │   公钥 + 一次性令牌 + 寻址提示  │  local mode  │
└──────┬──────┘                              └──────┬──────┘
       │ ② 局域网发现（mDNS / UDP 扫描）             │ 前台服务内
       └────────────── 每 5 秒重试 ─────────────────▶ │ 监听 :9527
                     ③ 挑战应答 → 加密会话            （密钥在本地）
                       ④ 规则 / 命令 / 报告 / 截屏
```

**关键设计：配对（一次性，确立身份）与寻址（每次，找当前地址）彻底分离。**
身份 = 设备密钥指纹；地址 = 每次通过 mDNS 现场解析。换网络只重做寻址，身份不变。

## 3. 配对协议（无服务器）

### 3.1 密钥材料
- 被控端首次启动本地生成：
  - `deviceId`：UUID（明文展示用）
  - 身份密钥对：X25519（用于会话密钥协商 + 签名），私钥存 `EncryptedSharedPreferences`（Android Keystore 支撑）
  - `pairingToken`：6 位随机令牌，60 秒有效、单次消费（存内存 + 短期持久化，重启失效）
- 家长端扫码后：X25519 交换 → HKDF 派生 **主密钥 M**（长期保存于家长端 Keystore）
- 被控端保存：设备私钥 + 已配对家长端公钥白名单（可多端）

### 3.2 配对信息载体（一期：手动配对码；三期：二维码）
- **一期**：被控端界面显示「设备 ID 前 8 位 + 6 位令牌 + 当前 IP:端口」，家长端手动输入。
  原因：二维码库需新增依赖，当前构建环境无法拉取包；纯手动码已足够完成配对语义。
- **三期**：改为二维码（内容见下），家长端扫码一步完成。
```json
{
  "v": 1,
  "deviceId": "…uuid…",
  "pub": "base64(X25519 公钥)",
  "token": "6 位令牌",
  "hint": { "ip": "192.168.1.23", "port": 9527, "service": "zzl-<id8>" },
  "exp": 1699999999
}
```
`hint` 仅为**扫码当下的寻址快捷方式**，过期或失效不影响后续（走 mDNS 重新发现）。令牌用掉即作废。

### 3.3 安全要求
| 项 | 要求 |
|---|---|
| 连接准入 | 仅接受"已配对家长端公钥"，其余来源直接拒绝并计数 |
| 挑战应答 | 被控端发 32 字节 nonce（+ 时间戳），家长端回 HMAC(M, nonce‖ts)，时间戳窗口 ±120s |
| 会话加密 | 每次会话用 HKDF(M, nonce) 派生 AES-256-GCM 密钥；截屏/密码等敏感字段强制加密 |
| 防重放 | nonce 单次有效；同 nonce 重复请求直接丢弃 |
| 可见性 | 被控端常驻通知显示"家长端已连接（本地）"，让孩子知情 |
| 限流 | 同一 IP 每分钟认证失败 > 10 次 → 临时拒绝 10 分钟 |

## 4. 发现与连接保持

### 4.1 发现（一级：mDNS）
- 被控端：`NsdManager.registerService("_zzl._tcp")`，服务名 = `zzl-<deviceId 前 8 位>`，端口 9527
- `ConnectivityManager.registerDefaultNetworkCallback` 感知网络变化 → **重新注册**（IP 变了必须重注册）
- 家长端：`discoverServices("_zzl._tcp")` → `resolveService` 拿当前 IP → 5 秒周期重扫（mDNS 缓存 TTL 30s）

### 4.2 发现（二级：UDP 广播扫描，兜底 AP 隔离）
- 被控端额外监听 UDP 9528：收到 `{"probe":"<deviceId>"}` → 回 `{"pub":…,"port":9527}`
- 家长端向 `255.255.255.255:9528` 广播探测（可指定子网广播地址），收集应答
- 适用于 mDNS 被路由器屏蔽的访客网络/多 VLAN 场景

### 4.3 发现（三级：手动输入 IP）
家长端可手动填写 `192.168.x.x`，走同一套挑战应答。

### 4.4 连接状态机（家长端 UI）
`未连接 → 搜索中（显示已发现设备数）→ 认证中 → 已连接（显示设备名/IP/延迟）`
- 断线：指数退避重连（1s/2s/4s…上限 30s），每轮先重新发现
- 重连成功后：携带 `stateVersion` 拉增量（**复用现有机制**），离线期间的变化一次性补齐

## 5. 本地通道 API（局域网内，路径前缀 `/local/v1`）

| 方法 | 路径 | 说明 | 对应服务器能力 |
|---|---|---|---|
| POST | `/auth/challenge` | 取 nonce + 时间戳 | —（新增） |
| POST | `/auth/verify` | HMAC 校验，换会话令牌 | 替代 JWT 登录 |
| GET | `/state` | 心跳 + 实时状态（前台应用/剩余额度/锁定态） | `/heartbeat` |
| GET | `/policy` | 拉取整份策略包 | `GET /policy` |
| PUT | `/policy` | 更新策略（总时长/时段/名单/逐应用/计时方式） | `PUT /policy`、`/policy/bundle` |
| POST | `/pin/verify` | 家长密码离线校验（复用本地 PBKDF2） | `/pin/verify` |
| POST | `/command` | 锁定/解锁/强制授权/加时 | `/commands` |
| GET | `/usage/summary` | 今日汇总 + 趋势 | `/usage/summary` |
| GET | `/usage/daily` | 按日排行（沿用服务端聚合口径） | `/usage/daily` |
| GET | `/usage/sessions` | 时间线（聚合同应用 ≤60s 碎片） | `/usage/sessions` |
| GET | `/blocks` | 拦截记录 | `/blocks` |
| GET | `/audit` | 审计事件 | `/audit` |
| GET | `/screenshot` | 截屏（分块 + Range 断点续传） | `/screenshot/:id` |
| GET | `/time-requests` / POST `/time-requests/:id` | 加时申请与审批 | 同名服务器接口 |
| POST | `/export` / `POST /import` | 加密数据包导出/导入（跨网兜底） | 新增（二期） |

一期范围调整：加时审批与逐应用规则编辑走二期（一期先交付总时长等顶层策略、锁定/解锁、实时状态）；
配对令牌有效期为服务运行期间、单次使用。

**约定**：所有响应体与服务器 DTO **完全同构**（复用 `PolicyBundleDto`、`UsageSessionDto` 等），
家长端只需在"数据源"一层做模式切换，**界面层零改动**。

## 6. 数据归属与冲突

| 数据 | 本地模式默认 | 可配置 |
|---|---|---|
| 策略/名单/规则 | 双方各自本地库（被控端执行 + 家长端备份） | 「同步到云端账号」开关，默认关 |
| 使用会话/汇总/截屏/审计 | 被控端本地库；家长端连接时拉取并写入**家长端本地历史库** | 同上 |
| 云端历史 | 不写入 | 开关打开时按现有接口上传 |

- **冲突规则**：本地模式期间的改动默认只作用于本机（`localOnly` 标记），不覆盖云端；
  家长在别处改了云端规则，重新连上后默认**云端优先**并提示冲突，家长可选择"以本机为准"回写。
- 家长端本地历史库沿用 Room（家长 flavor 已有依赖）。

## 7. 与服务器模式共存（不影响现有功能）

1. **新增独立模块** `child/local/`、`parent/local/`，不修改现有 `ApiService`、网络层与服务器 DTO 解析路径。
2. 家长端新增**模式选择**（首次启动引导 + 设置页可切换）：
   - 服务器模式：登录 → 服务器地址 → 配对码（**原逻辑完全不变**）
   - 本地模式：扫码配对 → 局域网发现（**不经过任何服务器接口**）
3. 家长端 `ParentViewModel` 增加 `ModeSource` 抽象（`ServerSource` / `LocalSource`），
   现有 ViewModel 逻辑通过接口取数；**服务器实现零改动**，本地实现独立新增。
4. 被控端本地服务仅在 `本地模式已开启` 时注册监听与 mDNS，**关闭时零开销**（不 bind、不注册）。
5. 现有单测（415 项后端 / 109 项 Android）必须全绿，作为回归红线。

## 8. 实施计划（分期）

### 一期：能连上、能管规则（本次交付）
- 被控端：密钥生成/存储、二维码展示、`/local/v1` 最小接口集（auth/state/policy/command/pin）、
  前台服务内 HTTP 监听（9527）、mDNS 注册 + 网络切换重注册
- 家长端：模式选择页、扫码配对、发现与连接状态机、服务器 DTO 复用、策略编辑/锁定/加时走本地通道
- 不含：报告与截屏（沿用"未连接时不可用"的提示）、UDP 扫描、导出导入
- 验收：同一局域网内完成配对→改规则→设备即时生效→锁定/解锁；拔网线重插后自动重连

### 二期：报告与审计
- 报告/时间线/拦截/审计/截屏接口 + 家长端本地历史库 + 断点续传
- UDP 广播扫描兜底 + 手动输入 IP

### 三期：跨网兜底与打磨
- 加密数据包导出/导入（微信/USB 传递）
- 多家长端邀请码、与云同步开关、冲突合并 UI
- 功耗优化（连接空闲时降频、mDNS 周期可配）

## 9. 风险与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| 熄屏/待机后连不上（Doze 冻结） | 高 | 亮屏后自动恢复；UI 明确提示「请点亮屏幕」；导出/导入兜底 |
| 路由器 AP 隔离 | 中 | UDP 广播扫描 + 手动 IP |
| 前台服务被 ROM 杀（联想 ZUI 尤其） | 高 | 复用现有保活三层 + 巡检自愈；本地服务随前台服务生命周期重建并重注册 mDNS |
| 明文局域网被旁路监听 | 中 | 全通道加密 + 挑战应答 + 仅接受已配对公钥 |
| 端口冲突/防火墙 | 低 | 端口可配置 + 失败时回退 9529/9530 |
| 与服务器模式代码纠缠 | 中 | 严格模块隔离 + 数据源接口抽象 + 回归测试红线 |

## 10. 需要确认的产品决策

1. 家长端默认模式：**服务器**（保持现状）还是**本地**（0 配置体验）？建议默认服务器，本地作为并列选项，避免老用户行为突变。
2. 本地模式是否允许"再开一个服务器账号做云备份"？建议允许但默认关闭。
3. 二维码是否需要图形化美化（当前是纯文本二维码）？建议一期先用现成二维码库，稍后统一视觉。
